# The Scattered Shore (तटीय चेतना / विखुरलेला किनारा) - Official Web Reader

An atmospheric, trilingual web reader for the progression fantasy webnovel **The Scattered Shore**.

## Features

- **Trilingual Language Toggle**: Read seamlessly in **English (EN)**, **Hindi (हिन्दी)**, and **Marathi (मराठी)**.
- **Chapter Navigator**: Quick top navigator, bottom previous/next buttons, and full drawer table of contents with live search.
- **Reading Modes & Themes**:
  - **Frost Abyss** (Default dark teal/ice aesthetic)
  - **Obsidian** (Pure black OLED)
  - **Sepia** (Warm parchment paper)
  - **Light** (Crisp minimalist white)
- **Typography Controls**:
  - Custom font switcher: Serif (Lora / Noto Serif Devanagari), Sans (Noto Sans Devanagari), and Display (Cinzel / Eczar).
  - Adjustable font size, line spacing (compact, normal, relaxed), and standard/wide margins.
- **Dynamic 'final chapters' Folder Loader**:
  - Click **"Load Chapters"** in the top header or directory drawer to import your local `final chapters` folder.
  - The reader parses markdown files on the fly directly in the browser with zero server upload needed.

## Hosting on GitHub Pages

This static website is deployed directly via GitHub Pages on the `main` branch.
